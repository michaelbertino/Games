# Harvest Quest

Original Game Boy Color orchard adventure; open project.gbsproj in GB Studio 4.3.2.
Each of the three fields has nine trees in three rows.

D-Pad: move. A: work on a nearby unfinished tree, from any direction.
B: enter/exit the tractor once unlocked. START: progress.
Trees do not block walking. Shaking takes 0.2 seconds and changes leafy
almond trees into bare branches above scattered almonds. SWEEP turns these
into a solid windrow; PICKUP clears the windrow. Finish each stage across
all nine trees before the next stage unlocks. Each field awards one token.

At one token, the barn door opens. Enter and interact with the tractor.
It doubles movement speed and works an entire three-tree row per A action.
At three tokens, the packing shed door opens. Enter to finish.
START on the completion screen returns to title and resets a new game.

Build: build/HarvestQuest.gbc. Original PNG art and editable native events.
